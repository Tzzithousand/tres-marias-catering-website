8. REQ-008: SESSION TIMEOUT (15-MINUTE INACTIVITY WATCHDOG & WINDOW CLOSE)
--------------------------------------------------------------------------------
Files:
- Admin/assets/js/dashboard.js
- Admin/assets/js/login.js

- Immediate Tab/Window Close: Session credentials stored in sessionStorage (cleared
  automatically when the tab or window is closed).
- 15-Minute Inactivity Watchdog:
  * Monitors user activity events (mousemove, mousedown, keydown, touchstart, scroll, click).
  * Stores throttled timestamp of last user activity in sessionStorage.
  * Checks elapsed inactivity time every 5 seconds, on window focus, and on tab visibility change.
  * If 15 minutes of inactivity elapse, automatically purges the JWT session
    and redirects the administrator to login.html?reason=inactivity.
- Inactivity Notice Banner:
  * login.js checks for reason=inactivity query parameter and displays:
    "Your session has timed out due to 15 minutes of inactivity. Please log in again."
